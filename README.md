# ATCS Unit 0 Demo

A simple Python calculator used during the **Advanced Topics in Computer Science (ATCS) Professional Software Engineering Bootcamp**.

## Current Features

- Addition
- Subtraction

## Running the Program

From the repository root, run:

```bash
python src/calculator.py
```

## Project Structure

```text
atcs-unit0-demo/
├── README.md
├── src/
│   └── calculator.py
└── docs/
    └── requirements.md
```

## Purpose

This repository is intentionally small. During Unit 0, students will use it to practice a professional development workflow:

**Problem → Issue → Acceptance Criteria → Branch → Change → Commit → Pull Request → Review → Merge**
