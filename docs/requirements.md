# Calculator Requirements

## Current Requirements

The calculator must:

1. Add two numbers.
2. Subtract two numbers.
3. Display the result clearly.

## Acceptance Examples

| Input / Operation | Expected Result |
|---|---|
| 5 + 3 | 8 |
| 5 - 3 | 2 |
| -2 + 4 | 2 |
| 0 - 7 | -7 |

## Future Features

The following features are intentionally not implemented yet. They will be used as Unit 0 engineering work items.

- Multiplication
- Division
- User input
- Input validation
